# Money Hunter — ทีมนักสำรวจหารายได้ (รันบนคอม 24/7 ของเรา)

> ชุดเริ่มต้นนี้ไม่ได้สัญญาว่าจะได้เงิน มันคือ **ระบบ** ให้ Claude Code ทำงาน "หา → คัด → ผลิต → แพ็กพร้อมอัปโหลด"
> ส่วนคนทำแค่ **อนุมัติ + กดอัปโหลด/ยืนยันตัวตน วันละ ~15–20 นาที**

## 1. ภาพรวมทีม (ทุกตัวคือ Claude Code คนละ prompt)

```
          ┌─────────── คอม 24/7 (Task Scheduler / cron) ────────────┐
  06:10   │ 🔭 SCOUT    หาเทรนด์/ช่องทาง/ช่องว่างตลาด ทั่วโลก        │ → opportunities/YYYY-MM-DD-*.md
  13:40   │ 🛠 BUILDER  เลือกไอเดียที่ได้คะแนนสูงสุด แล้วผลิตของ     │ → outbox/<ชิ้นงาน>/ (ไฟล์+คำบรรยาย+tag+prompt รูป)
  อาทิตย์  │ 📊 REVIEW   อ่าน ledger.csv ดูอะไรขายได้ ตัดตัวที่ไม่เวิร์ก │ → reports/weekly-*.md
          └────────────────────────────────────────────────────────┘
                     ↓ คุณเปิดดูวันละครั้ง
  👤 คุณ: อนุมัติ → สร้างรูปใน ChatGPT / วิดีโอใน Veo ตาม prompt ที่เตรียมไว้ → กดอัปโหลด → จดยอดขายใน ledger.csv
```

ทำไมคนยังต้องกดเอง: ChatGPT ฟรี และ Veo ฟรี **ไม่มี API** ให้สั่งอัตโนมัติ และแพลตฟอร์มขาย/รับเงินเกือบทั้งหมด
ห้ามบอทสมัครบัญชี + บังคับยืนยันตัวตน (KYC) ด้วยตัวเจ้าของ — ถ้าฝ่าฝืน บัญชีโดนแบนพร้อมเงินค้างจ่าย

## 2. ช่องทางที่เข้ากับของที่เรามี

ดู [`channels.md`](channels.md) — ตารางทุกช่องทาง + ถอนเงินเข้าไทยได้ทางไหน + กฎเรื่องงาน AI

## 3. ติดตั้ง (ครั้งเดียว ~30 นาที)

1. ติดตั้ง Claude Code บนคอม 24/7 แล้ว `claude` ล็อกอินด้วยบัญชี Pro
2. clone repo นี้ลงคอม แล้ว `cd money-hunter`
3. ทดลองรันมือก่อน: `./scripts/run.sh scout` (Linux/Mac) หรือ `.\scripts\run.ps1 scout` (Windows)
4. ตั้งเวลา
   - Windows: Task Scheduler → Create Basic Task → รัน `powershell -File C:\...\money-hunter\scripts\run.ps1 scout` ทุกวัน 06:10 และ `... builder` 13:40, `... review` วันอาทิตย์
   - Linux/Mac: `crontab -e` → ดูตัวอย่างใน `scripts/run.sh`
5. (ไม่บังคับ) ติดตั้ง **Claude in Chrome** บนคอมนั้น ล็อกอินเว็บต่าง ๆ ด้วยตัวเองใน Chrome ครั้งเดียว
   → ต่อไปสั่ง Claude ให้กรอกฟอร์มอัปโหลดให้ได้ (ตัวเองกดยืนยันขั้นสุดท้าย) โดย **Claude ไม่ต้องรู้รหัสผ่านเลย**

> ⚠️ แพ็กเกจ Pro มีโควตาใช้งานเป็นรอบ ๆ (ใช้ร่วมกับตอนคุณแชตเอง) จึงตั้ง 2–3 รอบ/วัน ไม่ใช่วิ่งต่อเนื่อง 24 ชม.

## 4. ข้อมูลส่วนตัว / รหัสผ่าน — ทำแบบนี้

| อย่าทำ | ทำแทน |
|---|---|
| ส่งรหัสผ่าน, เลขบัตร, เลขบัญชี มาในแชต | เก็บใน **Bitwarden** หรือ **KeePassXC** บนคอมตัวเอง |
| ใส่ไว้ในไฟล์ใน repo (แม้ repo private) | `.gitignore` กัน `secrets/`, `*.env`, `*.kdbx` ไว้ให้แล้ว |
| ให้บอทสมัครบัญชี/ยืนยันตัวตนแทน | สมัครเอง (ใช้ `signup-checklist.md` ที่บอทเตรียมคำตอบไว้) ใช้ 2FA ทุกบัญชี |
| ให้บอทล็อกอินด้วยรหัส | ล็อกอินเองใน Chrome แล้วให้ Claude in Chrome ทำงานในเซสชันนั้น |

## 5. กติกากันพัง (อยู่ใน `CLAUDE.md` ด้วย)

- คุณภาพ > จำนวน: แพลตฟอร์มตอนนี้ตรวจจับ "AI ปั่นจำนวน" แล้วปิดบัญชี/ตัดรายได้ (KDP, YouTube, Etsy, stock)
- บอกว่าเป็นงาน AI ทุกที่ที่แพลตฟอร์มถาม
- ห้ามลอกแบรนด์/ตัวละคร/ลายลิขสิทธิ์, ห้ามรีวิวปลอม, ห้ามเปิดหลายบัญชีบนแพลตฟอร์มเดียว
- ทุกรายได้จดใน `ledger.csv` — อาทิตย์ละครั้ง REVIEW ตัดช่องทางที่ 4 สัปดาห์ไม่มียอดทิ้ง
